Formulario Esencial de Consulta Rápida — Cálculo 1

1. Límites y Continuidad

  • Continuidad en x = c: f(c) existe, límx→c f(x) existe y ambos valores coinciden.
  • Removible: Existe el límite bilateral pero difiere de f(c).
  • De salto: Límites laterales finitos pero diferentes.
  • Infinita: Al menos un límite lateral tiende a ±∞.

2. Reglas de Derivación y Tangente

  • Definición: f '(x) = límh→0 [f(x + h) − f(x)] / h
  • Producto: (fg)' = f 'g + fg'  |  Cociente: (f/g)' = (f 'g − fg') / g2
  • Cadena: [f(g(x))]' = f '(g(x)) · g'(x)
  • Trascendentes: (eu)' = euu';  (ln u)' = u'/u;  (tan u)' = sec2(u)u'
  • Tangente: y − y0 = f '(x0)(x − x0)

3. Análisis de Curvas (f, f ', f '')

  • Monotonía: f ' > 0 ⇒ crece;  f ' < 0 ⇒ decrece.
  • Criterio 2.ª Derivada (si f '(c) = 0): f ''(c) < 0 ⇒ Máximo local;  f ''(c) > 0 ⇒ Mínimo local.
  • Concavidad: f '' > 0 ⇒ cóncava arriba (∪);  f '' < 0 ⇒ cóncava abajo (∩).
  • Inflexión: Cambio de concavidad en un punto continuo.

4. Cinemática y Economía

  • Movimiento: v(t) = s'(t),  a(t) = v'(t) = s''(t).
  • Rapidez |v(t)|: Aumenta si v y a tienen igual signo; disminuye si tienen signos opuestos.
  • Utilidad: U(x) = I(x) − C(x), con I(x) = x · p(x).
